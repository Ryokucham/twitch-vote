1お題と選択肢

空欄の選択肢はパネルに出ません。10個入れてもスクロールせず、すべて表示されます。

2進行

「締め切る」は投票受付を止めます。アンケートはその時点で最多得票の選択肢が自動で勝ちに決まります。賭博はこの時点では結果未確定で、最多得票でも勝ちにはなりません。

結果の確定 ― 締切とは別の操作 未確定

アンケートは締切と同時に最多得票の選択肢が自動で勝ちになるので、ここで選ぶ必要はありません。賭博は締切後に、実際の結果になった選択肢をここで選んでください。選んだときだけ、勝ちバッジ・結果バナー・紙吹雪が出ます。

3ダミー投票

投票中だけ票を入れられます。まずは「投票スタート」を押してみてください。

4Twitch連携

連携すると、Twitchで開始したアンケート／賭博が自動でこのパネルに反映されます。手入力・ダミー投票は連携中は不要になります（確認用に残ります）。

未連携Client IDを入れて「Twitchと連携」を押すと、Twitchの許可画面に進みます。許可は初回のみで、トークンの期限が切れたら再度許可します。
このページの公開URLそのもの（末尾に ? や # を付けない形）を登録してください
  1. dev.twitch.tv でアプリを新規作成し、上のリダイレクトURLを登録
  2. 発行された Client ID を上に貼って「Twitchと連携する」を押す
  3. Twitchの許可画面で許可 → このページに戻り、自動でEventSubに接続します
  4. その後はTwitch側（ダッシュボード／チャットコマンド）で投票を開始すれば自動反映されます。アンケートは最大5択、賭博は2択がTwitch側の上限です

権限（スコープ）は読み取り専用の channel:read:polls / channel:read:predictions のみを要求します。トークンはこのタブの中だけで保持し、URLやサーバーには出しません。

5配信用モード（OBS）

配信用モードは パネルだけ・背景透明 で表示します。操作パネルは映りません。下のURLをOBSのブラウザソースに貼って使ってください。

このページの公開URL + ?stream=1
  1. OBS：ソースの「＋」→「ブラウザ」→新規作成
  2. URLに このページの公開URLの末尾へ ?stream=1 を付けたもの を貼り、幅 400 / 高さ 760 前後に設定（選択肢が多いときは高さを上げる）
  3. OBS側でTwitch連携するときは、ブラウザソースを右クリック→「対話」を開きます。未連携のときはパネルの下に小さな連携バーが出るので、そこで Client ID を入れて許可してください（連携後はバーは消えます）。許可画面から戻っても配信用モードのまま自動接続します。トークンはOBS側のタブ内だけで保持され、URLには含めません
この画面を配信用プレビューにするパネルだけ表示に切り替えます。戻すときはURLの ?stream=1 を外してください

6プリセット

使い方 ― 配信までの流れ

  1. Twitch連携 ― 右の「Twitch連携」カードでアプリ登録 → Client IDを貼る → 許可する（初回のみ）
  2. 配信用URLを作る ― このページの公開URLに ?stream=1 を付けて、OBSのブラウザソース（幅400・高さ760前後）に貼る。OBS側では「対話」を開き、未連携時に出る小さな連携バーからTwitch連携を許可する
  3. 配信で使う ― Twitch側でアンケート／賭博を開始すると、配信用パネルに自動で反映されます。手動操作は未連携時のテスト用です
